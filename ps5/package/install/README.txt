Dead Space 2 for PS5 - put your game files here.

  /data/homebrew/PPSA94108/install/

What goes in this folder (any file names, sub-folders are looked through too):

  1. Your own Dead Space 2 (World) (En,Fr,Es) Xbox 360 Disc 1, as an .iso.
     Disc 2 as well if you have it: with both here the game changes disc by
     itself and never asks for one.
  2. Dead Space 2 Title Update #2, the package file as it is (no extension):
       TU_12K226V_000000C000000.00000000000G3
     Title Update #1, or an update for another release of the game, won't do.
  3. Optional: the Dead Space 2: Severed package from your Xbox 360
     (Content/0000000000000000/454108DF/00000002/ on its drive).

Then start the app. The first start checks the files against the ones this
build was made from and gets the game ready (a few seconds; Severed takes
longer). The disc images have to stay here: the game reads its data straight
from them. The title update and Severed packages can be deleted afterwards.

If something is missing or isn't the right release, the app says so on screen.

No game files come with this app: you need your own copy of the game.
