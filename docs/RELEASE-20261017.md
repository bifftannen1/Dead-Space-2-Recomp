TU2 prerelease playtest.

Download **DS2-TU2-Playtest-20261017.zip** for the launcher, game executable and required runtime files. Extract it, run **DS2Launcher.exe**, and select your own discs, Title Update 2 and optional Severed DLC.

- English and French voices; Spanish text/subtitles with English voices.
- Campaign and DLC are not fully tested. Expect bugs and report issues with your chapter, GPU and latest log.
- Source code and the toolbox are available in this repository and the source downloads below. No game data is included.
